# ARG-013 · Twitter OAuth (oauth/request_token) отдаёт HTML вместо API-ответа — вход через Twitter не работает

**Исполнитель:** Backend Lead · **Severity:** SEV-3 · **Начало:** 04.09 16:40 UTC · **Обнаружено:** 04.09 18:40 (через 130 мин) · **Закрыт:** 04.09 20:30

## Что происходит

С 04.09 16:30 растут ошибки `Twitter integration error` при запросе oauth/request_token: вместо JSON Twitter возвращает HTML-страницу (`<html lang="en" class="icecream">`). Ошибки идут на 220 из 282 хостов и из всех крупных стран, то есть проблема не в конкретном узле или регионе, а во внешнем провайдере или в нашей OAuth-конфигурации. Такая же сигнатура уже была 24–26.08: 3246, 4956 и 1236 строк в сутки. Затем она почти пропала и снова начала расти: 195 строк 02.09, 760 — 03.09, 2213 — 04.09. 5xx нет, RPS и CPU не выросли.

## Симптомы

- `Twitter integration error` по пути oauth/request_token: за окно 897 + 403 строк, пик 90 строк за 10 мин при обычном уровне 0 (по детектору)
- Суммарно по всем вариантам шаблона — с 37–39 строк за 10 мин до 16:30 до 118–158 строк за 10 мин с 16:50
- В теле ответа Twitter вместо JSON пришёл HTML (`<!DOCTYPE html> ... class="icecream"`), чаще всего с callback domain=site.example (912 строк), hi.site.example (244) и mirror.example (81)
- Ошибки на 220 из 282 хостов, максимум на одном хосте — 25 строк (kube0566), т. е. по хостам они распределены равномерно
- Все затронутые клиенты анонимные (anonymous_share 1,0): пользователи не могут войти через Twitter
- 5xx нет (0 строк), RPS 89,4 тыс./с против 108,2 тыс./с вчера, CPU 28,4 % против 47,8 %: нагрузка не растёт

## Возможные причины

1. **На стороне Twitter/X сбой или изменение OAuth 1.0a API: request_token отдаёт HTML-страницу ошибки вместо API-ответа** — В теле ответа HTML со страницей twitter (`class="icecream"`). Ошибки идут со всех хостов и из всех стран (IN 326, US 324, GB 184 клиентов). Инфраструктурных сигналов нет _(уверенность: высокая)_
2. **Наше приложение в Twitter Developer Portal отключено или ограничено: отозваны ключи, превышен лимит тарифа или callback URL не в whitelist** — Та же сигнатура 24–26.08, затем почти ноль и снова рост с 02.09 (195 → 760 → 2213 строк в сутки). Есть callback-домены hi.site.example и mirror.example, которых может не быть в списке разрешённых _(уверенность: средняя)_
3. **Twitter блокирует или ограничивает запросы с наших egress-IP** — Ошибки идут с большинства хостов одновременно, это согласуется с блокировкой на уровне исходящих IP. Прямых данных нет _(уверенность: низкая)_
