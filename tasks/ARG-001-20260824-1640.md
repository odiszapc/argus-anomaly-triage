# ARG-001 · Рост RPS в 1,4 раза за счёт трафика из IN; CPU до 44,3 %, ошибок почти нет

**Исполнитель:** PaaS Engineer · **Severity:** SEV-2 · **Начало:** 24.08 16:40 UTC · **Обнаружено:** 24.08 17:00 (через 30 мин) · **Закрыт:** 24.08 19:50

## Что происходит

С 16:30 до 17:00 24.08 RPS вырос с 95299 до 109689 за 10 мин при обычных ~80001,6 (ratio 1,4), и рост идёт плавно примерно с 15:50. Почти весь прирост даёт Индия: sampled hits/s по IN выросли с 21837,7 (15:50) до 40164,2 (17:00), а US и DE не растут. Трафик органический: мобильные ISP Reliance Jio и Bharti Airtel, тысячи разных IP. Поток ошибок остаётся малым. CPU вырос с 21,7 % до 44,3 % — пока запас есть, но ёмкость нужно держать под наблюдением.

## Симптомы

- RPS: 78236,7 (15:50) → 109689 (17:00) за 10 мин; обычно ~80001,6, ratio 1,4; запросов в окне 189,2 млн, прирост 50,2 млн
- IN: 21837,7 → 40164,2 hits/s (sampled) с 15:50 по 17:00; BD 2828,5 → 4527,5, PK до 1397,17; US (~8818–9345) и DE (3536,33 → 2889,33) без роста
- CPU app-серверов: 21,7 % (15:50) → 44,3 % (17:00), растёт вместе с RPS
- Ошибки малы: в бакете 17:00 2063 строки, 492 5xx; в 16:30–17:00 в IN 1121 строка ошибок с 1079 IP, из них 272 5xx
- Ошибки из IN идут с массовых мобильных ISP: Reliance Jio (489 строк / 471 IP), Bharti Airtel (449 / 431)
- Отдельный одиночный всплеск RPS 133493 в 14:20 — с текущим ростом не связан, проверить отдельно

## Возможные причины

1. **Органический рост трафика из Индии (вечерний пик, маркетинговая кампания, внешний реферал или изменения в поисковой выдаче/SEO)** — Прирост почти целиком из IN (21837,7 → 40164,2), рядом растут соседние BD и PK; рост плавный, без скачка; ошибки распределены по тысячам IP крупных мобильных операторов _(уверенность: высокая)_
2. **Ботовый или скрейпинговый трафик через мобильные сети IN** — Подтверждений нет: на одно IP приходится ~1 строка ошибки (1079 IP на 1121 строку), ISP — обычные потребительские. Проверить user-agent и эндпоинты нельзя: ошибок слишком мало _(уверенность: низкая)_
3. **Нехватка ёмкости или запоздалый автоскейлинг при дальнейшем росте** — CPU удвоился (21,7 % → 44,3 %), но 5xx пока малы (492 в бакете 17:00). Сейчас это риск, а не причина _(уверенность: низкая)_
