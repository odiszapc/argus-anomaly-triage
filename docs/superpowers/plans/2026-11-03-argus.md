# Argus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A service that watches app metrics and error logs, detects anomalies without look-ahead, and for each one writes a triage task (`tasks/*.md`), Slack payloads (`slack-log.json`) and a post-mortem draft (`postmortems/*.md`), with an LLM analyst, a second-model arbiter, dedup and early-warning predictions.

**Architecture:** Statistics find and group anomalies (cheap, deterministic, testable). An LLM agent with read-only SQL tools turns each incident into hypotheses and a task; code checks every number it cites; a local model from another family votes independently; rules + analyst + arbiter vote on the assignee, and a split vote goes to a human. One `Engine.tick(now)` drives three modes: `run` (cron), `watch` (resident) and `replay` (simulated live clock over history, which also measures time-to-detect).

**Tech Stack:** Python 3.12, uv, DuckDB (+Parquet/zstd), pandas/numpy, Jinja2, Typer, Claude Agent SDK (Claude Sonnet 5.5 analyst; works with `ANTHROPIC_API_KEY` or a Claude Code login), Ollama (`qwen3:14b` arbiter, `qwen3-embedding:0.6b` for dedup), MCP Python SDK, pytest, ruff, Docker.

**Spec:** `AI Automation Engineer Test.pdf` (the assignment) + the pre-build comparison of solution variants (variant B chosen: statistics + LLM agent + code-checked numbers). EDA facts: [`docs/analysis.md`](../../analysis.md).

## Global Constraints

- Inputs: `rps.csv` (`Time`,`Current`), `cpu-usage.csv` (`Time`,`AVG Current`, fraction 0..1), `rps-by-country.csv` (wide, `topk(10)` → `undefined` means *missing*, never 0), `endpoint-timings-ms.csv` (30-min step, wide, `undefined` = missing), `logs.json` (NDJSON, 16 GB, `application_client` is a JSON string). Time = epoch ms UTC.
- Bucket = 600 s. A bucket is labelled by its **end**: label `T` covers `[T-10m, T)` — same convention as the metrics.
- **No look-ahead:** any score, SQL tool result or text produced at `now` uses only data with `ts < now`. A test pins this.
- Roles (exact strings): `DBA`, `PaaS Engineer`, `SEO Specialist`, `Backend Lead`, `Security Lead`.
- Outputs (exact paths, relative to `--out`, default repo root): `tasks/`, `postmortems/`, `slack-log.json`; channels `#app-alerts` and `#app-alert-predictions`.
- Task text, Slack text and post-mortems are in Russian; identifiers, log templates and code in English.
- Only aggregates and ≤50-row SQL results leave the machine; `ARGUS_LLM=local` keeps every model call on Ollama; `ARGUS_LLM=off` uses deterministic templates (CI and offline).
- Every LLM-written number must be found in the evidence pack or a tool result (±1.5 % or same 2 significant digits); otherwise it is marked `⚠ не подтверждено` and the task gets `verification: partial`.

## Review Focus

- Missing points (topk `undefined`, log gaps during the 09-02 outage) must read as "no data", not as a drop to zero → test in Task 3 (`test_country_missing_is_not_zero`) and Task 2 (`test_csv_undefined_is_nan`).
- Single-point RPS doublings without CPU/country support must not page anyone → Task 3 `test_rps_spike_without_corroboration_is_artifact`.
- A level shift that lasts days (lock-wait regression) must stay one incident, not re-open every day → Task 4 `test_long_regression_is_one_incident`.
- Re-running `argus run` over the same window must not duplicate tasks or Slack posts (idempotent state) → Task 6 `test_rerun_is_idempotent`.
- LLM unavailable or returning junk must still produce a valid task (deterministic fallback) → Task 7 `test_analyst_failure_falls_back`.

### Task 2: Causal baselines and segmenter

**Files:** `detect/baseline.py`, `tests/test_baseline.py`

**Interfaces — produces:**
- `seasonal_baseline(s: pd.Series, days=7, min_days=2, fallback=12) -> pd.Series` — median of the same time-of-day over previous days; trailing median of the previous `fallback` buckets when history is short. Uses only past values.
- `robust_scale(resid: pd.Series, window=432, floor=...) -> pd.Series` — 1.4826·MAD of past residuals.
- `segment(flags: pd.Series, open_k=1, close_m=3, gap=2) -> list[tuple[ts, ts]]` — hysteresis episodes.

- [ ] Tests: `test_baseline_is_causal` (changing values after `t` leaves baseline at `t` unchanged), `test_seasonal_uses_same_time_of_day`, `test_fallback_on_short_history`, `test_segment_merges_small_gaps`, `test_segment_closes_after_m_quiet`.
- [ ] Implement, pass, commit.

### Task 3: Detectors

**Files:** `detect/logs.py`, `detect/metrics.py`, `detect/countries.py`, `detect/security.py`, `model.py` (Signal), `tests/test_detectors.py`

**Interfaces — produces:** `Signal(kind, key, label, start, end, peak_at, value, baseline, score, attrs)`; each detector `detect(store: Store, now: datetime, cfg) -> list[Signal]`. Kinds: `log_burst`, `new_signature`, `log_gap`, `rps_shift`, `rps_artifact`, `cpu_high`, `latency`, `country_shift`, `bot_activity`.

Initial thresholds (calibrated on data in Task 9, then frozen in `config/argus.yaml`): log burst `z≥6 & n≥30 & ratio≥3`, close `ratio<1.5` for 3 buckets; new signature `unseen ≥6h & n≥20`; rps artifact `rps_ratio≥1.5 & cpu_ratio<1.15 & countries_ratio<1.15`; country shift `|ratio-1|≥0.4` for ≥3 buckets and `|country_ratio-global_ratio|≥0.3`; cpu `≥85 %` for ≥2 buckets; bot `top-ISP share≥0.3 & ips/requests≥0.8`.

- [ ] Tests (synthetic frames): `test_burst_detected`, `test_new_signature`, `test_rps_spike_without_corroboration_is_artifact`, `test_country_missing_is_not_zero`, `test_country_shift_vs_global`, `test_bot_rotation_features`.
- [ ] Implement, pass, commit.
